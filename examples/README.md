# Tres pruebas sugeridas

1. DS: predecir primer fondeo dentro de 7 días. Documentar fecha de corte, cohorte elegible, fuga temporal, baseline y métrica; NO usar identificadores reales.
2. AI: asistente de consulta de movimientos de inversión. Definir permisos por cliente, límites de herramienta, errores, datos sensibles, set de evaluación y AI Gateway.
3. Frontend: pantalla de activación con estado de primer fondeo. Definir estados, contrato API, accesibilidad y telemetría sin exponer PII.

Para cada caso ejecutar el comando de especificación del perfil, `/speckit.plan`, `/speckit.tasks` y el comando de revisión del perfil; revisar la calidad con un humano antes de implementar.
